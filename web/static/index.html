Implantação Corporativa no Firewall & DHCP (Sem Instalar Nada nos Endpoints)

Basta apontar o DNS no DHCP corporativo ou Firewall (Fortinet, pfSense, Mikrotik, Cisco, Sophos, Windows Server) para este servidor

1

Defina o IP Fixo do Servidor CoorpDNS

O IP do CoorpDNS na rede local ou DMZ (ex: 192.168.1.100). Configure reserva de MAC ou IP estático no servidor.

2

Acesse as Configurações de DHCP do Firewall ou Switch L3

No console de gerenciamento de rede (ex: pfSense, FortiGate, Mikrotik RouterOS ou DHCP do Windows Server), abra as opções do escopo da LAN/VLANs.

3

Configure o CoorpDNS como Servidor DNS Principal

Insira o IP do CoorpDNS como DNS Primário. Para evitar contorno de bloqueio por parte de usuários, defina o mesmo IP no DNS Secundário ou aponte para um nó CoorpDNS secundário.

4

Aplique e Proteja Todas as Estações de Trabalho

Todos os computadores da empresa, laptops em Wi-Fi corporativo e servidores membros receberão o CoorpDNS imediatamente, aplicando políticas por grupo e auditoria de 180 dias!

🏢 Integração com Active Directory & Domínios Locais

💡
Como as máquinas se comunicam com o Controlador de Domínio (DC)?

O Windows AD exige registros SRV internos (como _ldap._tcp.dc._msdcs.seudominio.local e _kerberos) para logon, GPOs e permissões. Ao cadastrar a zona do seu AD abaixo, o CoorpDNS intercepta e encaminha essas consultas diretamente ao IP do seu Domain Controller, garantindo autenticação perfeita, enquanto toda a navegação para a internet continua recebendo bloqueio de anúncios e relatórios por máquina!
